# DropShelf Icon Pack

Production-ready vector assets for the wooden shelf/drawer identity.

## AppIcon
- `DropShelf_AppIcon_Master.svg`: primary dimensional vector master.
- `DropShelf_AppIcon_Simplified.svg`: reduced-detail variant for very small contexts.
- PNG exports: 1024, 512, 256, 128, 64, 32, 16 px.
- `DropShelf.icns`: ready for the macOS app bundle.
- `DropShelf.iconset/`: complete Xcode/macOS iconset source.

## MenuBar
- `DropShelf_MenuBar_Template.svg`: monochrome macOS template glyph.
- `DropShelf_MenuBar_Drop_Template.svg`: drag/drop state.
- PNG exports at common 1× and 2× menu-bar sizes.

For AppKit/SwiftUI, import the template SVG/PDF and set the NSImage as a template image so macOS automatically handles light/dark appearance.

## Toolbar
Separate SVG vectors and PNG exports for:
- Shelf
- Drop
- Move / Copy
- Multiple Items
- History
- Settings
- Pin
- Clear

## Marks
`DropShelf_Mark.svg` is the compact shelf + downward-arrow brand mark for badges, website favicon, onboarding, and marketing use.

All SVGs use editable vector paths and gradients; there is no embedded raster artwork.
